This run used actual pinned Qwen 0.5B CPU inference and real authored tools. DescGen failed for the formula tool due to invalid identifier mapping; normalization DescGen succeeded. DynVer rejected a malformed verification plan. Original-condition agents often reached step limits; both refined conditions remained unavailable. The pipeline still generated and hash-validated the 236-file handover ZIP. No original paper experiment or T4 run was performed. The exact source for this initial run is inside its handover archive, outside Git; the committed manifest records the pre-commit dirty source fingerprint.

The initial exact fixture oracle also required an agent finish message. The final implementation separately records agent_finished and counts objective evidence when the actual intended tool/arguments/result are observed, matching the stated target-invoked AND objective-observed definition. final_oracle_recheck.json is an explicit reanalysis of the same saved traces under this final authored oracle, not a new inference run. Original files are unchanged. No new full/lite observations are invented.
