# Limitations and reproduction gaps

1. Exact author implementation, prompts, tool selection, task texts, seeds, commits, labels, judge rubric and serving configuration were not obtained. Expiry is confirmed for the suggested anonymous repository, but its official connection remains unverified. Search failure is not proof no release exists.
2. SliceMin is a restricted Python AST reconstruction. TypeScript, automatic dispatch/fallback, class/nested/higher-order resolution, global alias analysis and full framework registration semantics are absent. Unresolved calls can hide relevant behavior. Module context over-includes irrelevant statements. File/byte limits do not guarantee bounded parser complexity for every adversarial input.
3. Optional LLM rewrites are syntactically constrained, not semantically proven. Entry arguments cannot be guessed from one observed use. Recursion/default mutation/external effects can invalidate informal pruning. No rewritten source is executed or deployed.
4. Comment removal, identifier truncation and contextual filtering do not eliminate every prompt-injection channel. Behavior-bearing literals remain untrusted. Renamed attributes/imports are reasoning artifacts and may not execute equivalently. Truncation collisions currently block processing.
5. Replay decisions are hand-authored simulation of semantic stages. They validate dataflow/error handling and exercise actual safe fixture functions, but cannot measure LLM hallucination, reasoning quality, attacker success, semantic fidelity or model cost.
6. Real untrusted MCP execution remains disabled. Fixed trusted fixtures are not a sandbox or LangChain/MCP reproduction. No containment claim follows from the review-only Docker plan or existing sandbox-exec binary.
7. DynVer filters once and does not implement the paper's unspecified iterative repair protocol or free-form argument correction. Inconclusive claims are omitted from supported output without being labeled false. Input schema structural fields are not separately behaviorally certified. A judgment is evidence for tested cases, not proof of universal validity.
8. No original-model experiments ran. Provider APIs were mocked in transport tests; small-model GPU inference was prepared but not run. The public Qwen option is not equivalent to original commercial models or gpt-oss-120b on four Blackwell GPUs.
9. Original paper TSR is a proxy for downstream agent usefulness, not a complete semantic-quality metric. Generated task selection, manual judgments, unknown task-set sharing across generation models, unavailable repeat counts and intersection-conditioned overhead limit conclusions. Published narrative/table inconsistencies are preserved and discussed.
10. All original-condition measured/difference fields remain blank. Local timings include file writes and Python allocation instrumentation and omit LLM/network latency. They cannot be compared with paper generation cost. Memory peaks are Python allocations, not total RSS/GPU memory.
11. Local core was validated on macOS Python 3.13.9; the portable source was also checked with Python 3.11. Actual Colab runtime availability, package installation and CUDA compatibility remain external conditions. Optional GPU dependency pins are a proposed environment, not a fully resolved tested lockfile.
12. The future capstone policy layer, behavioral malware detection, explanation UI, online MCP gateway and hybrid trust score are outside this implementation. No improvement or production readiness is claimed.
